## 1. Product Vision & Goals

DopaMint is an autonomous AI agent execution platform built in San Francisco. It provides a full squad of specialized autonomous agents (trading, onchain swaps, finance, travel booking, calendar management, inbox automation, shopping, research) governed by a deterministic, cryptographically-signed **Trust Layer**.

The landing page showcases:
1. **Agency with Bounded Authority:** Showing that agents can execute real-world tasks (payments, bookings, onchain transactions) without being given an unbounded blank check.
2. **Interactive Trust Layer & Policy Engine:** Allowing users to test policy thresholds, risk assessments, and tamper-evident action receipts in real-time.
3. **Voice Native & Messaging Ubiquity:** Demonstrating iMessage (via Linq API) and real-time sub-80ms voice calling.
4. **Onchain Actions & x402 Machine Payments:** Native HTTP-402 protocol settlements, DEX swaps, and CEX execution under strict policy bounds.
5. **Multi-Agent Delegation & Bounded Failure Modes:** Explaining isolated execution, memory provenance, and automatic freeze triggers on violation.
